# MUSEUM OF SOUND｜聲音博物館

一座以「深胡桃木 × 奶油白 × 古銅金 × 酒紅色」為視覺基調的線上華語與世界流行音樂策展博物館。

## 專案特色
- **四大主題常設展區**：
  - `01｜香港與華語經典`：張國榮、Beyond、王菲、陳奕迅、鄧紫棋
  - `02｜世界流行音樂`：Michael Jackson、Air Supply、Westlife、Aerosmith、Bon Jovi、Queen
  - `03｜台灣樂團與獨立音樂`：蘇打綠、五月天、美秀集團、芒果醬
  - `04｜華語創作與 R&B`：周杰倫、陶喆、方大同、嚴爵、李聖傑、張震嶽、玖壹壹
- **黑膠旋轉展示與經典專輯收藏牆**：重現唱片博物館的陳列氛圍。
- **多維度音樂探索**：支援關鍵字、展區、年代、地區、曲風交叉篩選，以及 LocalStorage「我的收藏」功能。
- **合法官方收聽導覽**：全站不提供未授權音檔或完整歌詞，統一導向 Spotify 與 YouTube 官方平台。

## AI 協作規範（AGENTS.md）
本專案根目錄附有完整的 `AGENTS.md`，定義了資料格式（`assets/js/artists.js`）、四大展區規則、色彩系統與新增展間 SOP，讓 AI 可隨時依照相同規範擴充新音樂人與專輯。

## 本機預覽與 GitHub Pages 部署
1. 直接以瀏覽器開啟 `index.html` 即可本機預覽（無需安裝任何套件）。
2. 將整個專案資料夾內的檔案上傳至 GitHub Repository 根目錄。
3. 前往 Repository 的 **Settings → Pages**，在 **Source** 選擇 `Deploy from a branch`，Branch 選擇 `main` 與 `/ (root)`，儲存後即可透過 GitHub Pages 公開瀏覽。
